# ATM Bank Simulation

## Overview

The rapid advancement of technology has significantly transformed many sectors, including banking. One of the most impactful innovations in modern banking is the Automated Teller Machine (ATM), which allows customers to perform financial transactions quickly and conveniently without visiting a bank branch. Through an ATM, users can withdraw cash, check account balances, transfer funds, and access various banking services.

This project is a Bank ATM Simulation developed to demonstrate the implementation of fundamental programming concepts in a real-world scenario. The application simulates basic ATM functionalities such as user authentication, balance management, cash withdrawal, and fund transfers.

## Objectives

* Understand the basic logic behind digital banking systems.
* Implement user authentication and transaction processing.
* Practice programming concepts through a practical project.
* Simulate common ATM operations in a simple and interactive environment.

## Features

* User login authentication
* Balance inquiry
* Cash withdrawal
* Fund transfer
* Transaction management

## Technologies Used

* Programming Language: C
* Development Environment: Visual Studio Code

## Educational Purpose

This project was developed as a learning exercise to improve understanding of programming logic, data handling, and the fundamental processes involved in ATM-based banking systems.
